# VXI-11 の実装可否と工数評価

## 結論

**初期リリースでは VXI-11 を実装せず、TCP Raw Socket を先に完成させます。**

`InstrumentTransport` インターフェースは通信方式から独立させてあるため、
後から VXI-11 実装を追加できます。Raw Socket 実装へ VXI-11 固有の処理を混在させません。

## VXI-11 とは

VXI-11 は TCP/IP 上の計測器制御プロトコルで、ONC RPC（Sun RPC）の上に構築されています。
PC 環境では NI-VISA や PyVISA が内部でこれを扱うため、利用者がプロトコルを意識することはありません。

通信手順の概略は次のとおりです。

1. ポート 111 の portmapper へ `GETPORT` を送り、VXI-11 Core チャンネルのポート番号を得る
2. 得られたポートへ RPC 接続し、`create_link` でリンクを確立する
3. `device_write` / `device_read` で SCPI コマンドと応答をやり取りする
4. 必要に応じて Abort チャンネル、割り込みチャンネルを別ポートで確立する
5. `destroy_link` で終了する

## Android で実装する場合の課題

| 課題 | 内容 |
| --- | --- |
| ライブラリが無い | Android で使える信頼できる VXI-11 / ONC RPC ライブラリが実質存在しない。JVM 向けの `remotetea`（ONC RPC）は Java EE 時代の実装で、Android 用のメンテナンスや API レベル対応が保証されない |
| XDR の自前実装 | ライブラリを使わない場合、XDR エンコード／デコードと RPC メッセージ組み立てを自前で書く必要がある |
| ポートマッパー | ポート 111 への問い合わせが必要。ファイアウォールや機種設定で無効な場合がある |
| 3 チャンネル構成 | Core / Abort / Interrupt の複数チャンネルを扱うと接続管理が複雑になる |
| デバッグの困難さ | バイナリ RPC のため、疑似サーバー側も RPC を実装しないとテストできない |
| 検証手段が無い | 実機モデルが未確定で、VXI-11 が有効かどうかも未確認 |

## 工数見積り

| 作業 | 見積り |
| --- | --- |
| XDR エンコード／デコード | 2–3 日 |
| ONC RPC クライアント（portmap + call/reply） | 3–4 日 |
| VXI-11 Core チャンネル（create_link / write / read / destroy_link） | 2–3 日 |
| Abort チャンネルとタイムアウト・キャンセル処理 | 2 日 |
| 疑似サーバー側の VXI-11 実装（テスト用） | 3–4 日 |
| 統合テストとデバッグ | 3–5 日 |
| **合計** | **15–21 日** |

## リスク

- **得られる利点が小さい**: Tektronix 4000 シリーズは Socket Server による Raw Socket 通信に対応しており、
  本アプリの用途（波形取得、測定、設定変更）は Raw Socket で完結します。
- **仕様逸脱の危険**: RPC 層を自前実装すると、機種側の実装差で原因の切り分けが難しくなります。
- **保守負担**: プロトコル層を自前で持つと、以後の Android バージョン変更にも自力で追随する必要があります。

## Raw Socket を優先する判断

1. Tektronix 4000 シリーズは Socket Server（既定ポート 4000）に対応している
2. Raw Socket は `java.net.Socket` だけで実装でき、Android の Ethernet バインドと組み合わせやすい
3. 疑似サーバーを平易な TCP サーバーとして実装できるため、実機なしで自動テストできる
4. 応答形式が SCPI のテキストと IEEE 488.2 バイナリブロックのみで、解析対象が明確

## 将来 VXI-11 を追加する場合

`InstrumentTransport` を実装した `Vxi11Transport` を `core:network` へ追加します。
アプリ側の SCPI エンジン（`core:scpi`）は通信方式を知らないため、変更は不要です。

現状は `Vxi11Transport` を「未実装」を明示的に返すスタブとして置き、UI 上でも選択できないようにしています。
