実機のモデルは未確定です（判明しているのは「Tektronix 4000 シリーズ」のみ）。
本アプリは特定モデル決め打ちを避け、接続後に識別して対応機能だけを有効化します。

### 補足

- **デジタル CH**: MSO は標準搭載。MDO は MSO 相当のデジタル入力を持つ構成があるため
  `CONFIGuration:DIGITAl:NUMCHANnels?` の結果で判断します。
- **AFG / DVM / ARB**: ハードウェア搭載かつライセンス有効の場合のみ利用できます。
  `CONFIGuration:AFG?` / `CONFIGuration:DVM?` / `CONFIGuration:ARB?` で判定します。
- **`CONFIGuration:*?`**: Gen 2 以降のマニュアルで確認済み。Gen 1 は未確認のため
  未定義ヘッダーを検出したらモデル名推定へフォールバックします。
- **VXI-11**: いずれの世代も本アプリでは未実装です。
  → [vxi11-feasibility.md](vxi11-feasibility.md)

## Capability 検出の優先順位

1. `*IDN?` でメーカー・モデル・シリアル・ファームウェアを取得
2. `CONFIGuration:*?` を試行（**非破壊**）
3. 未定義ヘッダーなら SCPI エラーキューで検出し、モデル名からの推定へフォールバック
4. 安全な Query の試行結果で補正
5. いずれも判定できない項目は「不明」として UI 上で無効化

**機能検出のために本体設定を破壊的に変更することはしません。**

## モデル名からの推定規則（フォールバック）

Tektronix 4000 シリーズのモデル名は `<接頭辞>40<帯域コード><チャンネル数><世代>` の形を取ります。

| 要素 | 推定内容 | 例 |
| --- | --- | --- |
| 接頭辞 `DPO` | アナログのみ | DPO4054 |
| 接頭辞 `MSO` | アナログ + デジタル 16 ch | MSO4104 |
| 接頭辞 `MDO` | アナログ + RF、デジタルと AFG はオプション | MDO4104C |
| 数字部の末尾 | アナログチャンネル数 | `4054` → 4 ch、`4032` → 2 ch |
| 末尾 `B` / `C` | 世代 | MSO4104B → Gen 2 |

この規則はあくまでフォールバックです。`CONFIGuration:*?` が使える機種では常にそちらを優先します。
推定に失敗した場合はアナログ 2 ch のみを有効化し、他は「不明」として無効化します。
