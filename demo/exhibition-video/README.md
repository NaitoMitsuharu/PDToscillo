# PDToscillo 展示会用デモアニメーション

完成画面ではなく、展示用の操作イメージを示す45秒・無音の16:9ブラウザアニメーションです。オシロスコープ操作の難しさを導入に置き、オシロスコープとAndroid端末をLAN接続する図から始めます。接続機器を自動判別し、将来はPDT-FP1を含むLAN対応計測機器へ対応を広げる構想も示します。画面右下に「表示データはシミュレーション」と明記しています。

## 録画

1. `index.html` を Chrome / Edge で開く。
2. ブラウザを全画面表示にする（F11）。表示サイズは 16:9 にする。
3. `R` キーを押して先頭から再生し、画面録画を開始する。
4. 45 秒後のループ直前で録画を停止する。

Space キーで一時停止・再開、R キーで先頭へ戻ります。音声は、録画後にナレーションまたはBGMを重ねる想定です。

## MP4の生成

`record-animation.mjs` は、Three.jsアニメーションをフレームキャプチャし、45秒・1920×1080・無音のMP4を生成します。FFmpeg EssentialsとPlaywrightが必要です。

```powershell
node .\record-animation.mjs
```

## 実アプリ録画へ移行する場合

プロジェクト内の疑似オシロスコープを起動し、Android エミュレータから `10.0.2.2:4000` へ接続します。

```powershell
./gradlew :simulator:run --args="--port 4000 --model MDO4104C --shape SINE"
```

その後、Appium で「接続 → 波形取得 → 測定 → 自動測定」を決まった順序で操作し、エミュレータの画面録画を行います。未完成・未検証の画面は、この展示用アニメーションを維持するほうが安全です。
